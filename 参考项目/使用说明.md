# GitHub 项目核实与使用说明

本次查询了六个公开 GitHub 项目，读取原始 README、许可及相关源码，并在《核实记录.json》保存查询时的提交号。五项进入了本次工作，第六项仅完成评估。没有把项目链接当成已安装的 Skill，也没有声称运行了五个独立游戏。

| 项目 | 许可 | 本次落地 |
|---|---|---|
| [Three.js](https://github.com/mrdoob/three.js) | MIT | 实际运行 Three.js 0.181.2；参照骨骼混合示例，继续使用 AnimationMixer 的动作权重、上下身分层和渐变切换。新增圆角几何、卡通角色、战斗数字与场景资产加载。 |
| [glTF Transform](https://github.com/donmccurdy/glTF-Transform) | MIT | 实际运行 CLI 4.2.1 的 dedup / resample / prune，优化本次重新导出的 GLB。具体体积见模型规格与校验结果。 |
| [glTF Validator](https://github.com/KhronosGroup/glTF-Validator) | Apache-2.0 | 实际运行 npm 工具校验新人物的材质、骨骼、六动画和缓冲区。结果落盘，不以能打开作为格式验收。 |
| [Kenney 3D Platformer](https://github.com/KenneyNL/Starter-Kit-3D-Platformer) | 代码 MIT / 资产 CC0 | 实际导入 cloud.glb 与 grass.glb 的几何，移除外部色板依赖并换成本游戏纯色材质。阅读金币、HUD、角色控制脚本，参考奖励反馈与易上手设计；本游戏独立实现逐关星级和轻松模式，未移植 Godot 引擎。 |
| [drei ContactShadows](https://github.com/pmndrs/drei) | MIT | 阅读软接触阴影源码，采用接地阴影的设计原则。为现有原生 Three.js 独立实现共享径向渐变贴地阴影，减少重复深度渲染；未安装 React / drei，也未把静态贴地阴影称为完整 ContactShadows。 |
| [ActionPoser](https://github.com/Arminando/ActionPoser) | GPL-2.0 | 阅读姿势分组、动作区间及骨骼选择机制。现有 Blender NLA 和手写骨骼已能覆盖六动作，因此未安装、未复制插件源码；保留为后续复杂约束绑定的候选。 |

本地技能实际使用：brainstorming 与 writing-plans 用于设计和实施安排；game-ui-frontend 用于 HUD 与手机布局；web-3d-asset-pipeline 用于导出优化校验；Blender 用于建模流程。Blender 实际执行使用本机 5.2.2 LTS 的独立后台场景，没有操作用户当前打开的场景。webapp-testing 用于真实 Chromium / Playwright 验收。Skill 来源是本机已安装版本，不把项目参考说成新增安装成功。

人物模型是根据用户照片在本地独立制作的可爱卡通版本；五官几何、服装、头发和帽子重新构建，没有贴真人脸照片。辨识目标是发型、柔和脸型、眼形和服装特征；没有 3D 扫描，不能保证真人 100% 还原。原始照片不进入公开仓库。
